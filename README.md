# 澳门书院防诈宣传静态网站

公开网址：<https://liangtakwai.github.io/macau-scam-prevention/>

项目仓库：<https://github.com/LIangtakwai/macau-scam-prevention>

`main` 分支更新后，GitHub Actions 自动发布四个页面与 `assets`、`materials` 资源。

根据 `提示词.docx` 制作，使用 HTML、CSS、JavaScript，无后端、数据库、注册或发帖功能。页面内容都在本地运行；仅在「常见问题解答」页点击「AI 提问」时，问题才会发送至 DeepSeek API 用于生成回答。

## 打开网站

双击 `index.html`，推荐使用 Chrome 或 Edge。也可在根目录启动任意静态 HTTP 服务器。四个页面可以独立访问和互相跳转，无需安装网站依赖。

## 页面一览

- `index.html`：首页。整屏封面：项目名 Scam Prevention Campaign、两枚标志、两个入口——了解骗局 / 求助。
- `types.html`：认识诈骗类型。可横向滑动的卡片轨道（10 类诈骗、7 个案例），宣传视频放在页面最下面，卡片以图片作封面、只留两行摘要；点卡片进入**铺满整屏的详情页**；顶部 ‹ › 、键盘左右方向键、底部的「下一个类型 / 下一个案例」都能直接切到下一条，不用返回列表。返回按钮支持浏览器后退与 Esc。另有 14 条高危信号。卡片封面取自宣传视频画面，存放在 `materials/covers`。每个类型的详情页底部先列「出处」（定义与本地案例来源），再接「延伸观看 · B 站」，每个类型 2–3 条相关视频，共 27 条，均逐条打开核对过（2026-10-30）。每个案例详情页底部标注「出处」与核对状态；案例 1、2、3、7 附原始报道链接，案例 4–6 标注为课程材料改编并列出相近报道。
- `faq.html`：常见问题解答。「搜索问题或答案」输入框兼作 AI 检索：输入关键词即时筛选 35 个问答；按回车或点「AI 提问」时，先在站内材料中检索相关片段，再把片段与问题一起发送给 DeepSeek 大模型生成回答，并列出参考来源；下方另有 6 个模拟帖子。
- `help.html`：求助。应急三步、警方/校园/书院求助渠道、报案证据清单、官方资源链接（已标核实日期），下方为内容出处与核对说明。

## 项目结构

- `assets/css/style.css`：配色、排版、响应式与焦点样式。
- `assets/js/main.js`：四个页面的渲染、视频切换、关键词搜索、自测与 AI 提问逻辑。
- `materials/content.js`：网页实际读取的文字材料，与界面代码分离，支持直接打开 HTML。
- `materials/content.json`：同一内容的 JSON 备份，方便编辑或迁移，由 `scripts/sync_content.py` 同步。
- `materials/ai-config.js`：AI 提问的接口配置（地址、代理、模型、上下文条数等），只在 FAQ 页加载；当前为浏览器直连，`apiKey` 为明码 key，会随公开仓库与网页源码可见（项目组 2026-11-10 明确接受，见下文「AI 提问」）。
- `worker/`：可选的 Cloudflare Worker 代理源码与部署说明；如换成代理模式，密钥只存 Worker 环境变量，并带每日额度（默认全站 200 次/天、单 IP 30 次/天）。
- `materials/logos`、`materials/videos`：转换后的浏览器可用资源。
- `materials/案例.docx`、`materials/诈骗类型.docx`：原始资料副本。
- `防诈宣传资料来源与核查报告.docx`：黑白来源清单，列出 7 个案例、10 类诈骗及官方电话、法规、视频、B 站、AI 等全部来源与链接（2026-11-05）。详细比对版备份为 `防诈宣传资料来源与核查报告_详细版.docx`。
- `Pre分工与讲稿.docx`：按 5 人分工整理的展示讲稿（开场、三大类诈骗、Q&A、结尾求助电话），内容取自网站。
- `网站内容总表.docx`：把 materials 中网站实际用到的全部文字、出处、联系方式、素材清单整理成一份总文档（2026-11-10）。
- `scripts`：材料整理、页面生成、来源修订与视频转换辅助脚本；运行网站不需要这些脚本。

## 修改内容

日常修改可直接编辑 `materials/content.js` 中的对应字段，然后运行 `scripts/sync_content.py` 同步 JSON 备份。注意 `content.js` 内的对象必须保持严格 JSON 格式（双引号键值、无尾逗号、内部不写注释），否则同步脚本会报错并提示行列。

`scripts/apply_source_revisions.py` 是 2026-11-05 的一次性来源修订脚本：为 7 个案例写入原始报道链接与差异说明，为 10 类诈骗补 `sources` 字段并修正案例 2、3、7 的事实错误。再次运行会覆盖案例与类型文字，日常改稿后不要重跑。

`scripts/prepare_materials.py` 会从原始 Word 重新抽取类型与案例，并重新生成 FAQ、自测题、名词等维护字段；运行前请备份手工修改后的内容，因为脚本会覆盖 `content.js` 与 `content.json`。`scripts/build_pages.py` 生成四个 HTML 页面，修改导航或页面骨架后运行它即可。

网站并不在线解析 Word，材料在构建时抽取，网页运行时读取 `materials/content.js`。使用 `textContent` 渲染文字，材料内容不会作为 HTML 执行。界面采用固定导航、无衬线字体、深蓝与白色，优先适配桌面，同时支持手机和键盘操作。

## AI 提问（已并入 FAQ 搜索框）

- 工作流程：在「常见问题解答」页输入问题 → 本站材料（诈骗类型、案例、问答、名词、高危信号、求助渠道）本地检索最相关的若干片段 → 片段与问题一起发给 DeepSeek → 在搜索框下方展示回答与参考来源编号；下方的问答列表同时按关键词筛选。
- 只回答站内资料覆盖的问题；资料未覆盖时模型会明确说明并给出咨询热线，降低编造风险。
- API 请求失败时自动降级：直接展示站内最相关的常见问题，页面仍可使用。
- **每日额度**：Worker 默认全站 200 次/天、单 IP 30 次/天，按澳门时间 0 点重置；用完后返回 429，页面自动降级为站内检索，不会把额度刷爆。改额度、查看今日用量（`GET /quota`）与清零方法见 `worker/README.md`。
- **密钥与模式（重要）**：当前为浏览器直连，`materials/ai-config.js` 中写入明码 key，会随公开仓库和网页源码一起公开，任何访问者都能看到并直接调用——这是项目组 2026-11-10 明确接受的取舍。若要改成不公开的模式：按 `worker/README.md` 部署 Cloudflare Worker，把 `proxyUrl` 填成 Worker 地址、清空 `apiKey`，密钥只放 Worker 环境变量 `DEEPSEEK_API_KEY`。直连模式下建议定期更换 key（[DeepSeek 开放平台](https://platform.deepseek.com/api_keys)），换 key 时要改文件并重新部署。
- **隐私说明**：只有点击「AI 提问」时，问题才会发送至 DeepSeek API；单纯输入关键词筛选问答在本地完成，不上传数据。
- 回答由大模型生成，仅供参考，不构成法律建议；紧急情况请拨打报案热线 993。

## 部署

推送到 `main` 后，`.github/workflows/pages.yml` 会自动把四个 HTML、`assets` 与 `materials` 打包成 Pages 站点。首次使用需在仓库 Settings → Pages → Build and deployment → Source 选择“GitHub Actions”。

也可手动上传：将四个 HTML、`assets` 与 `materials` 放在同一目录即可。路径为相对路径，可部署在域名根目录或子目录。无需上传原始 `材料`、`.tools`、辅助脚本、报告或 QA 文件。

线上 AI 提问为浏览器直连：`materials/ai-config.js` 里的 key 会随网页公开，任何访问者都能看到。若要改成不公开的模式，按 `worker/README.md` 部署 Cloudflare Worker（含 `QUOTA` KV，用于每日额度），把 `proxyUrl` 填成 Worker 地址、清空 `apiKey`。公开发布前建议核实案例出处及联系方式，并确认视频素材与校徽的使用授权。
